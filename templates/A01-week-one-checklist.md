# Week-One Checklist

From *Forward Deployed AI Engineering* by Nasser Ghanemzadeh — Appendix A.1; see Chapters 6 and 8.

A forcing function for the first week. The goal of the first week is not to ship anything. It is to produce the artifacts and relationships that make the rest of the engagement possible. If you cannot tick off most of the items below by the end of the first week, the engagement is not yet set up to succeed.

- [ ] Eight discovery interviews scheduled across sponsor, blocker, line user, and regulator
- [ ] At least two discovery interviews completed
- [ ] Top-five-priorities check completed with the sponsor; the project is confirmed on the list
- [ ] Sponsor identified by name; their exception-granting authority confirmed in writing
- [ ] Domain rebel identified on the customer side and confirmed as a working partner for the engagement
- [ ] Production data access requested through the appropriate channel; expected timeline known
- [ ] Eval-set co-author identified from the customer's domain experts; first labeling session scheduled
- [ ] Success metric agreed in writing with the sponsor; the metric is in the customer's units
- [ ] Validation threshold agreed in writing; the threshold is one number the eval set will be graded against
- [ ] Three-week first-slice scope drafted; the slice is end-to-end and shippable on real data
- [ ] Stakeholder map produced and shared with the senior FDE or sponsoring partner
- [ ] Standing weekly meeting with sponsor on the calendar for the duration of the engagement
- [ ] Engagement repo created with the README structure from Chapter 14
- [ ] Telemetry schema decided; trace storage destination chosen and provisioned
- [ ] Eval suite repository scaffolded with the rubric documentation template
- [ ] First scoping document drafted (template A.2); sent to sponsor for sign-off
