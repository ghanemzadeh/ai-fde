# Templates

The working templates from Appendix A of *Forward Deployed AI Engineering*, one per file, ready to copy. The templates do not replace judgment. They give it a structure to work inside, so you can spend your attention on what is different about this engagement.

Adapt them. Trim what does not apply. Add what does.

| Template | Use it when | Book |
|---|---|---|
| [Week-one checklist](A01-week-one-checklist.md) | You are starting an engagement and need to know whether it is set up to succeed | A.1, Ch 6, Ch 8 |
| [Scoping document](A02-scoping-document.md) | You need the problem, metric, threshold and first slice agreed on one page | A.2, Ch 6 |
| [Engagement contract outline](A04-engagement-contract-outline.md) | You are negotiating a milestone-based deal | A.4, Ch 17, Ch 20 |
| [Weekly status update](A05-weekly-status-update.md) | It is Friday and the sponsor needs to scan progress in thirty seconds | A.5, Ch 12, Ch 16 |
| [Post-engagement synthesis](A06-post-engagement-synthesis.md) | The engagement has ended and its lessons need to reach the product team | A.6, Ch 7, Ch 12 |
| [Discovery interview script](A07-discovery-interview-script.md) | You have forty-five minutes with the person whose work the system will change | A.7, Ch 8 |
| [Eval rubric template](A08-eval-rubric-template.md) | You need the customer to agree in writing on what good means, before grading starts | A.8, Ch 9 |
| [Eval rubric, worked example](A08-eval-rubric-worked-example.md) | You want to see how specific a finished rubric is | A.8, Ch 9 |
| [Mock interview prep](A09-mock-interview-prep.md) | You have a customer-simulation interview tomorrow | A.9, Ch 15 |
| [Portfolio README template](A10-portfolio-readme-template.md) | You are packaging a portfolio project for a hiring manager | A.10, Ch 14 |
| [First-slice repository layout](ch10-slice-repo-layout.md) | You are about to make the first commit of a first slice | Ch 10 |
| [Trace schema](ch12-trace-schema.md) | You are deciding what to log on every request | Ch 12 |

The eval harness skeleton from A.3 is not a document. It is in [eval-harness/](../eval-harness/) as code you can run.

Each file opens with a note saying where it comes from in the book. Delete the note when you copy the template.
